# Support

- **Bugs and features:** open a GitHub issue using the templates.
- **Security:** see [SECURITY.md](./SECURITY.md) — do not file public issues for vulnerabilities.
- **Usage questions:** GitHub Discussions (if enabled) or a well-specified issue.

## Out of scope

- Custom professional services for private deployments (contact Manova commercially)
- Support for modified forks we do not maintain
- Guaranteed SLAs on free GitHub issues
