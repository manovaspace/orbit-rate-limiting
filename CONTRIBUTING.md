# Contributing

Thanks for contributing to **orbit-rate-limiting**.

## Code of conduct

This project follows [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md).

## Development

See [README.md](./README.md) for install and test commands.

## Pull requests

1. Fork and branch from `main`.
2. Keep changes focused; no client-specific product names or private URLs.
3. Add/update tests for behavior changes.
4. Use [Conventional Commits](https://www.conventionalcommits.org/): `feat:`, `fix:`, `docs:`, `chore:`.
5. Fill out the PR template checklist.

## Security

Do not open public issues for vulnerabilities — see [SECURITY.md](./SECURITY.md).
