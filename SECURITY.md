# Security Policy

## Supported versions

Security fixes are applied to the latest release on `main` and the latest semver tag when tagged releases exist.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security reports.

Prefer one of:

1. [GitHub private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) on this repository (Security → Report a vulnerability), or
2. Email maintainers via the contact listed on the [manovaspace organization](https://github.com/manovaspace) profile.

Include: affected version/commit, impact, reproduction steps, and any suggested fix.

We aim to acknowledge reports within **7 days** and to publish a fix or mitigation timeline after triage. We follow coordinated disclosure; please allow time to patch before public discussion.

## Scope

This policy covers this repository's source and published packages/images. Misconfiguration of your own deployment (weak secrets, exposed admin ports) is out of scope unless caused by unsafe defaults in this project.
